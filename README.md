# Genetic Algorithm Exam Scheduler

## COMP338 - Artificial Intelligence

### Course Project 1

## Description

This project implements a **Genetic Algorithm** to solve the exam scheduling problem. The system generates an optimized exam timetable by assigning courses to available exam slots while reducing conflicts and satisfying scheduling constraints.

The algorithm uses evolutionary techniques such as selection, crossover, mutation, and elitism to improve schedules over multiple generations.

## Features

* Generate exam schedules using Genetic Algorithms.
* Reduce student exam conflicts.
* Use fitness function penalties to evaluate schedules.
* Apply tournament selection, crossover, and mutation.
* Preserve the best solution using elitism.
* Display the final optimized timetable.

## Genetic Algorithm Process

The system works through the following steps:

1. Generate an initial population of random schedules.
2. Evaluate each schedule using the fitness function.
3. Select the best candidates using tournament selection.
4. Create new schedules using crossover.
5. Apply mutation to introduce diversity.
6. Repeat for multiple generations until a good schedule is found.
